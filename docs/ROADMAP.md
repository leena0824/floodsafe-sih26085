# 48-Hour Roadmap

## 0-8 hours

- Set up Next.js, FastAPI, PostgreSQL/PostGIS, and Docker Compose.
- Generate a small road graph and synthetic rainfall/drainage observations.
- Create database migrations and seed scripts.

## 8-20 hours

- Build the baseline model.
- Add `/roads`, `/reports`, `/alerts`, and `/health` endpoints.
- Add model explanations and confidence values.

## 20-32 hours

- Render a MapLibre risk map.
- Add a citizen report form and verification status.
- Add 15/30/60-minute forecast controls.

## 32-42 hours

- Add safe-route calculation.
- Add a municipal monitoring view.
- Add a language switcher and offline fallback message.

## 42-48 hours

- Test mobile responsiveness.
- Verify API and database behavior.
- Prepare a 3-minute recorded demo and fallback screenshots.
